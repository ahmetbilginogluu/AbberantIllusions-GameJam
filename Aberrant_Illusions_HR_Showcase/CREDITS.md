# Credits and content scope

Aberrant Illusions is a Unity platformer by Ahmet Bilginoğlu, published for Acerola Jam 0:
https://ahmetbilgi.itch.io/aberrant-illusions

This showcase contains 19 supplied project C# scripts, the player input action asset and three source level-art previews. The images were taken from Level1Test.png, Part2.1.png and Part2.3New.png in the supplied archive and renamed for readability; their bytes are unchanged.

The original project combines custom and third-party material. A complete per-file authorship/licence inventory was not included. No claim that every visible element is original artwork is made, and no blanket open-source licence has been applied.

Models, unrelated photographs/background textures, bulk art, fonts, package resources, scenes, materials, animations and audio are not redistributed in this showcase. References to audio and other excluded resources remain in the original scripts. Unity and Input System are external dependencies rather than project-authored libraries.
